## 4. AI 어댑터

상단 **[⚙ AI 어댑터]** → 모드 선택.

- **시뮬레이터**(기본): API 키 없이 동작. 결정론적 예시 초안.
- **OpenAI**: `chat/completions` + `stream:true`.
- **Anthropic**: `messages` + `stream:true`, `anthropic-dangerous-direct-browser-access: true` 헤더.
- **Gemini**: `streamGenerateContent?alt=sse`.
- **로컬 FastAPI**: `/api/stream`(SSE)이 있으면 서버가 오케스트레이션까지 수행, 없으면 `/api/plan`으로 계획만 받아 브라우저가 타임라인을 재생합니다.

키는 `localStorage`(`feihel.adapter.v1`)에만 저장되고 화면·로그에 출력되지 않습니다.
연결 실패 시 **자동으로 시뮬레이터로 폴백**하고 타임라인에 경고를 남깁니다.

## 5. 로컬 백엔드 (사무실 데스크탑 + Tailscale)

```bash
cd office/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

export OPENAI_API_KEY=sk-...     # 선택
export LAB_TOKEN=우리연구실토큰    # 선택

uvicorn server:app --host 0.0.0.0 --port 8000
tailscale serve --bg 8000        # 사설망에서만 접근
```

- `GET /api/health` → `{"ok": true, "engine": "simulator"}`
- `POST /api/plan` `{"command": "..."}`
- `POST /api/stream` `{"command": "..."}` → `event: plan|task|log|result|done`

> 보안: 인증은 `LAB_TOKEN` 하나뿐입니다. **공인 인터넷에 노출하지 말고** Tailscale 사설망 안에서만 쓰세요.
> 브라우저에 API 키를 두는 방식은 데모·개인용 전제이며, 공용 PC에서는 쓰지 않는 것이 좋습니다.

## 7. 확장 지점

- `data.js`의 `PLAYBOOKS`에 연구실 실제 서식(지출결의서·회의록 양식)을 넣으면 카드가 그대로 결재 문서가 됩니다.
- DWG·Rhino·Grasshopper 결과(UTCI heatmap, 일조 다이어그램)를 카드 첨부로 연결하면 설계검토가 한 화면에서 끝납니다.
- 승인 결과를 캘린더·메일과 연결하면 "승인 → 발송 → 마감 추적"까지 이어집니다.
- 로컬 서버의 시뮬레이터를 실제 연구비 관리 시스템·코호트 서버 조회로 바꾸면 잔액·한도·표본 수가 실시간 값이 됩니다.
