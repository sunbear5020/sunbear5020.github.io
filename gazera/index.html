    GAZERA Core 0.2.0

    웹은 미리보기, 최종 보고서는 엔진으로. 정의는 동일합니다.

    # 1) 설치
pip install -e .
# 2) 합성 데모 데이터 생성
python -m gazera_core demo --out demo.tsv
# 3) 분석 → Excel · JSON · CSV
python -m gazera_core analyze demo.tsv --out results
# 4) 로컬 API
uvicorn api.server:app --port 8000

    저장소 구조: gazera_core/ (loader · cleaner · ivt · metrics · stats · exporter · synthetic · pipeline), api/server.py, tests/.

    • loader인코딩·구분자·머리말 자동 감지, 컬럼 자동/수동 매핑 (CSV/TSV만)
    • cleaner유효 시선 비율 · 추정 Hz · 결측률 · 시간 단조성 · 화면 밖 좌표 검사
    • ivt공개 문헌 기반 I-VT. 화면 기하로 px→deg 환산 후 응시/도약 분류
    • metrics응시 횟수·시간, 도약 빈도·진폭·속도, AOI 체류·방문·TTFF, AOI 전이행렬·시선 엔트로피
    • stats정규성 검정 후 t-test / Mann-Whitney / Wilcoxon, 효과크기, Holm 보정
    • provenance지표·통계의 수식·단위·DOI·경계(measured/derived/exploratory)
    • exporterExcel 다중 시트(+Methodology) · CSV · JSON(0.2.0) · Markdown 보고서

    어떻게 독립 구현했나

    표준 구분자 텍스트(CSV/TSV)만 읽는 벤더 중립 어댑터를 두고, I-VT 분류는 공개 논문(Salvucci & Goldberg, 2000)을 근거로 자체 작성했습니다. 데모·테스트 데이터는 100% 자체 생성한 합성 자료이며 실제 피험자 정보가 없습니다. 컬럼명은 자동 매핑을 위한 패턴으로만 쓰이고, 어떤 이름이든 수동 매핑할 수 있습니다.
