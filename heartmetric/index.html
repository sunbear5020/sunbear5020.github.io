심박과 숲을,
하나의 표로.

커프 혈압계에서 나온 SBP / DBP, 링·워치의 심박과 HRV, 그리고 걷던 곳의 기온 · PM2.5 · 녹지를 시각으로 결합합니다. 도시 가로와 산림치유 조건의 심혈관 반응을 같은 정의로 계산하고, 조건 간 차이를 효과크기와 함께 정리합니다. 파일은 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다.

100% 브라우저 실행 · 서버 불필요 클린룸 MIT 라이선스 Oura · Apple 비제휴 합성 데모 데이터 내장
경계

Oura Ring은 mmHg 혈압을 제공하지 않습니다. Oura API v2에 혈압 엔드포인트가 없어 HEARTMETRIC은 커프 측정만을 혈압의 근거로 삼고, 링·워치는 심박·HRV를 담당합니다. Apple Health는 HRV를 SDNN으로, Oura는 RMSSD로 보고하므로 둘을 서로 변환하지 않고 어느 쪽이 있는지 표시합니다.

03

조건별 비교

Welch t-test · Cohen's d · 95% 신뢰구간. A − B 방향으로 계산합니다.

↔
지표A 평균B 평균Δ (A−B)% Cohen's d효과p95% CI
조건이 두 개 이상 있는 데이터를 불러오면 비교표가 채워집니다.

효과크기 기준: |d| < 0.2 무시 · 0.2–0.5 작음 · 0.5–0.8 중간 · ≥ 0.8 큼. p는 다중비교 보정 전 값입니다.

06

Python 엔진 — 같은 정의, 같은 계산

워크벤치는 엔진의 정의를 옮긴 것입니다. 재현 연구는 Python으로.

# pip install -e ".[api,dev]"
from heartmetric_core import load_file, analyze, exporter

loaded = load_file("apple_health_export.xml")
bundle = analyze(loaded.frame, group_a="forest", group_b="urban")

print(bundle["summary"]["dipping"]["dipping_pct"])
exporter.save(bundle, "report.xlsx")   # 8 sheets

CLI

python -m heartmetric_core \
  --demo -o report.xlsx
