심박과 숲을,
하나의 표로.

커프 혈압계의 SBP / DBP, 링·워치의 심박과 HRV, 그리고 걷던 곳의 기온 · PM2.5 · 녹지를 시간 허용 오차로 결합합니다. 도시 가로와 산림치유 조건의 심혈관 반응을 같은 정의로 계산하고, 같은 사람의 두 조건은 대응표본으로 비교합니다. 파일은 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다.

100% 브라우저 실행 · 서버 불필요 다중 스트림 결합 · 허용 오차 선택 대응표본 · d_z · 순열검정 클린룸 MIT 라이선스
경계

Oura Ring은 mmHg 혈압을 제공하지 않습니다. Oura API v2에 혈압 엔드포인트가 없어 HEARTMETRIC은 커프 측정만을 혈압의 근거로 삼고, 링·워치는 심박·HRV를 담당합니다. Apple Health는 HRV를 SDNN으로, Oura는 RMSSD로 보고하므로 둘을 서로 변환하지 않고 어느 쪽이 있는지 표시합니다. 결합은 값을 옮기는 일이 아니라 열을 시간축에 나란히 놓는 일입니다.

03

조건별 비교

Welch t-test 또는 subject_id 대응표본. A − B 방향으로 계산합니다.

↔

대응표본을 켜면 같은 피험자의 두 조건을 짝지어 비교합니다.

지표A 평균B 평균Δ (A−B)% Cohen's d효과pq (BH)p (Holm)95% CI
조건이 두 개 이상 있는 데이터를 불러오면 비교표가 채워집니다.

효과크기 기준: |d| < 0.2 무시 · 0.2–0.5 작음 · 0.5–0.8 중간 · ≥ 0.8 큼. p는 지표별 원값이며, 같은 표의 지표를 한 가족으로 본 q(BH-FDR)와 p(Holm)를 나란히 표시합니다.

07

Python 엔진 — 같은 정의, 같은 계산

워크벤치는 엔진의 정의를 옮긴 것입니다. 재현 연구는 Python으로.

# pip install -e ".[api,dev]"
from heartmetric_core import align_streams, analyze, exporter

aligned = align_streams([
    "cuff_bp.csv", "wearable.json", "environment.csv",
], tolerance_minutes=30)          # 여기와 같은 규칙

bundle = analyze(aligned.frame, paired=True)   # subject_id 대응표본
exporter.save(bundle, "report.xlsx")          # 10 sheets
exporter.to_markdown(bundle, "report.md")

CLI

python -m heartmetric_core \
  -i bp.csv -i oura.json -i env.csv \
  --merge --tolerance-minutes 30 \
  -o report.md
